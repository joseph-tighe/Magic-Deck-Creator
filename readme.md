# Magic Deck Maker
A website that helps you build your a Magic the Gathering deck.

## Try it out
[https://joseph-tighe.github.io/Magic-Deck-Creator/](https://joseph-tighe.github.io/Magic-Deck-Creator/)

## How to use
Simply start searching for cards and add them to your deck. You can also filter by color, type, and mana cost.

## Features
- Get recommendations based on your current deck
- Search through all cards in Magic the Gathering
- Filter by color, type, and mana cost
- Quick stats on your deck
